# SciMath Feud

Local full-stack SciMath Feud app.

## Folders

- `frontend/` - React/Vite game UI
- `backend/` - Node/MySQL API and database schema

## Run Locally

Start the backend:

```powershell
cd backend
npm install
npm run dev
```

Start the frontend in another terminal:

```powershell
cd frontend
npm install
npm run dev
```

The frontend uses `http://localhost:3001` as the default API URL.
